# Plurimap för Windows

## [⬇ Ladda ner Plurimap-Setup.exe (senaste versionen)](https://github.com/jonatanchaglund-a11y/plurimap-releases/releases/latest/download/Plurimap-Setup.exe)

Kör filen när den laddats ner. Windows kan varna eftersom filen inte är signerad än: klicka **Mer info → Kör ändå**.

Utan licensnyckel körs appen i provläge (stor genomskinlig logga över utskriften). Licens köps på [plurimap.se](https://plurimap.se).

Alla versioner finns under [Releases](https://github.com/jonatanchaglund-a11y/plurimap-releases/releases).

---

**English:** [Download Plurimap-Setup.exe (latest version)](https://github.com/jonatanchaglund-a11y/plurimap-releases/releases/latest/download/Plurimap-Setup.exe). Without a licence key the app runs in trial mode. Licences at [plurimap.se](https://plurimap.se).
