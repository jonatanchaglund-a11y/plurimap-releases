# Plurimap för Windows

Installationsfilen finns under [Releases](https://github.com/jonatanchaglund-a11y/plurimap-releases/releases). Välj den senaste versionen och ladda ner `Plurimap-Setup.exe` under **Assets**.

Kör filen när den laddats ner. Windows kan varna eftersom filen inte är signerad än: klicka **Mer info → Kör ändå**.

Utan licensnyckel körs appen i provläge (stor genomskinlig logga över utskriften). Licens köps på [plurimap.se](https://plurimap.se).

---

**English:** The installer is available under [Releases](https://github.com/jonatanchaglund-a11y/plurimap-releases/releases): pick the latest version and download `Plurimap-Setup.exe` under **Assets**. Without a licence key the app runs in trial mode. Licences at [plurimap.se](https://plurimap.se).
